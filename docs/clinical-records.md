# السجلات السريرية — المرحلة 3.1

تؤسس هذه المرحلة استشارات سريرية منظمة دون خطط علاج أو وصفات أو موافقات أو صور. جميع بيانات الاختبار خيالية، ولا يعني هذا التصميم امتثالًا طبيًا أو قانونيًا دون مراجعة مختصة.

## النموذج وسير العمل

- `ClinicalEncounter` يربط العيادة والمريض والطبيب المعيّن، ويمكن ربطه بزيارة وموعد من العيادة نفسها. الاستشارة المستقلة مسموحة.
- `ClinicalNote` يحفظ أقسامًا محدودة: سبب الاستشارة، التاريخ ذي الصلة، الحساسيات، الأدوية، الإجراءات السابقة، الفحص، التقييم، والتوصيات.
- `MedicalHistory` سجل منظم واحد لكل مريض وعيادة، بإصدار ومراجع وتاريخ مراجعة.
- `ClinicalNoteAmendment` تصحيح لاحق ملحق، مع مؤلف وسبب وتوقيت ومحتوى مستقل.

المسار هو `DRAFT/IN_PROGRESS → SIGNED → AMENDED`. التوقيع صريح ولا ينهي الزيارة. بعد التوقيع يمنع مشغّل قاعدة البيانات تعديل المحتوى أو وقت التوقيع؛ التصحيح يضاف كسجل جديد. تستخدم الكتابات إصدارات متفائلة وتعيد تعارضًا عند الكتابة المتزامنة.

## الصلاحيات

| الدور | الوصول السريري |
|---|---|
| الطبيب | سجلاته المعيّنة، التاريخ الطبي، والتصحيحات |
| المالك/مدير العيادة | لا وصول تلقائي |
| الاستقبال/المحاسب | لا وصول |
| مدير المنصة | لا وصول تلقائي |

صلاحية `patients.read` إدارية ولا تمنح وصولًا سريريًا. يرى الطبيب فقط الاستشارات المرتبطة بعضويته النشطة. يستطيع مدير العيادة الذي يملك `staff.manage` إسناد دور الطبيب كعملية توظيف محددة، لكن ذلك لا يمنح المدير قراءة سريرية ولا يرفع سقف إسناد أدوار المالك أو الإدارة أو المحاسبة. لا توجد آلية وصول طارئ أو تجاوز عام.

## العزل والخصوصية

تحمل الجداول الأربعة `clinicId` وروابط مركبة من نفس العيادة، وتستخدم `ENABLE/FORCE ROW LEVEL SECURITY`. تمر العمليات عبر `TenantDatabaseService`. دور التشغيل ليس مالكًا ولا يملك `BYPASSRLS` أو `DELETE`.

تُسجّل عمليات الإنشاء والقراءة والتعديل والتوقيع والتصحيح دون نسخ المحتوى السريري إلى التدقيق. السجلات `SENSITIVE_PERSONAL`، ومشمولة بالنسخ الاحتياطي المشفر، لكنها مستبعدة عمدًا من تصدير المريض الإداري الحالي. الاحتفاظ محاكاة فقط ولا يحذف سجلًا.

## حدود المرحلة

تحتاج مشاركة السجل بين الأطباء، الوصول الاستثنائي، التوقيع القانوني، المصطلحات السريرية، الموافقات، مدد الاحتفاظ، وتصدير السجل السريري إلى حوكمة سريرية وقانونية قبل الإنتاج. لا توجد تشخيصات آلية أو توصيات علاجية.
